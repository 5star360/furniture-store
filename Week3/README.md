# 🛋️ Furnique – Week 3: JavaScript Filtering, Search & Animations

## Week 3 Focus
- Builds on Week 2 (product catalog from DB)
- Live search input filters products by name/description in real-time
- Category filter buttons filter products without page reload
- Card entrance animations on page load (fadeIn with stagger)
- All filtering done client-side with JavaScript

## What's NOT included yet
- No form validation (Week 4+)
- No login/session on catalog (Week 4+)
- No admin panel / CRUD (Week 5+)

## Database
- Name: `week3db`
- Import `week2db.sql` from Week 2, then update `includes/db.php`

## How to Run
1. Place folder in `htdocs/furniture-store/`
2. Run `setup/install.php` or import week2db.sql
3. Visit `http://localhost/furniture-store/`
