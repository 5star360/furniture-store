# 🛋️ Furnique – Week 2: Product Catalog HTML/CSS

## Week 2 Focus
- Connected to `week2db` database (imported from Week1db)
- Product catalog fetched from MySQL `products` table
- Responsive CSS grid layout (`products-grid`)
- Category filter via URL query strings (no JS yet)
- Hero section, footer with category links

## What's NOT included yet
- No JavaScript filtering/search (Week 3+)
- No form validation logic (Week 4+)
- No login/session integration on catalog (Week 4+)
- No admin panel / CRUD (Week 5+)

## Database
- Name: `week2db`
- Import `Week1db.sql` from Week 1, then update `includes/db.php`
- Or run `setup/install.php` fresh

## How to Run
1. Place folder in `htdocs/furniture-store/`
2. Update `includes/db.php`: change `week2db` if needed
3. Run `setup/install.php`
4. Visit `http://localhost/furniture-store/`
